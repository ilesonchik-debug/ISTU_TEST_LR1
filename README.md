## Текст задания

Разработать автоматизированные тесты для функции обработки массива действительных чисел.

Функция должна найти все соседние пары элементов массива \((a_i, a_{i+1})\), для которых первый элемент \(a_i\) кратен трём, а второй элемент \(a_{i+1}\) является отрицательным.

**Входные данные:** массив действительных чисел типа `double` произвольной длины.

**Результат:** массив пар, содержащих индекс и значение первого элемента, а также индекс и значение следующего за ним элемента. Если подходящих пар нет, возвращается пустой массив.

При проверке кратности трём используется остаток от деления первого элемента на три. Второй элемент пары должен быть строго меньше нуля.

## Используемые технологии

- Язык программирования: C#
- Среда выполнения: .NET 8
- Фреймворк автоматизированного тестирования: xUnit
- Генерация тестовых данных: Python
- Автоматизация тестирования: GitHub Actions
- Анализ покрытия кода: Coverlet

## Структура проекта

- `ClassLibrary/` — реализация тестируемой функции.
- `TestProject/` — проект автоматизированных тестов.
- `TestData/generate_tests.py` — скрипт генерации и проверки тестовых данных.
- `TestData/test_results.csv` — файл с исходными данными и ожидаемыми результатами тестирования.
- `.github/workflows/test.yml` — конфигурация автоматического запуска тестов.

## Организация тестирования

Тесты сгруппированы по проверяемым сценариям:

- проверка пустого массива и массивов из одного элемента;
- проверка пар, в которых первый элемент кратен трём;
- проверка отрицательных и неотрицательных значений второго элемента;
- проверка первого элемента, не кратного трём;
- проверка нуля как элемента, кратного трём;
- проверка отрицательных чисел, кратных трём;
- проверка дробных действительных чисел;
- проверка массивов с несколькими подходящими парами;
- проверка соседних и перекрывающихся пар;
- проверка правильности определения индексов и значений элементов;
- проверка массивов без подходящих пар;
- проверка массивов различной длины, включая длинные массивы.

Исходные данные и ожидаемые результаты формируются отдельным скриптом на Python. Полученные данные сохраняются в CSV-файл и используются автоматизированными тестами на C#.

## Автоматический запуск тестов

Для автоматизации проверки используется GitHub Actions. При отправке изменений (`push`) в любую ветку репозитория запускается workflow, который восстанавливает зависимости .NET и выполняет автоматизированные тесты.

Результат выполнения тестов доступен во вкладке **Actions** репозитория на GitHub.

## Назначение работы

Цель лабораторной работы — освоить методы структурного тестирования программного обеспечения на основе потокового графа, расчёта цикломатической сложности и построения базового множества независимых путей, а также методы тестирования на основе эквивалентного разбиения входных данных. Дополнительной целью является освоение автоматизации тестирования с использованием xUnit, Python и GitHub Actions.
