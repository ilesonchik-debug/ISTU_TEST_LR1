# Лабораторная работа 1

# Общие сведения

- Номер группы: `Б23-191-1зу`
- ФИО: `Баранов Алексей Владиславович`
- Номер задания: `7 вариант`

# Текст задания

Разработать автоматизированные тесты для функции обработки массива чисел.

Функция должна определять количество элементов массива, которые делятся на 5 без остатка, но при этом не делятся на 7 без остатка, а также вычислять сумму этих элементов.

Входные данные: массив чисел типа `double`.

Результат: количество подходящих элементов и их сумма.

## Используемые технологии

- Язык программирования: C#
- Среда выполнения: .NET 8
- Фреймворк автоматизированного тестирования: xUnit
- Генерация тестовых данных: Python
- Автоматизация тестирования: GitHub Actions

## Структура проекта

- `ClassLibrary/` — реализация тестируемой функции.
- `xunittest/` — проект автоматизированных тестов.
- `xunittest/TestData/` — генератор тестовых данных и файл с результатами генерации.
- `.github/workflows/test.yml` — конфигурация автоматического запуска тестов.

## Организация тестирования

Тесты сгруппированы по проверяемым сценариям:

- проверка базовой логики и условий отбора элементов;
- проверка граничных значений;
- проверка областей эквивалентности;
- проверка расположения подходящих элементов в начале, середине и конце массива;
- проверка массивов, не содержащих подходящих элементов;
- проверка массивов с несколькими подходящими элементами.

Исходные данные и ожидаемые результаты формируются отдельным скриптом на Python.

## Автоматический запуск тестов

Для автоматизации проверки используется GitHub Actions. При отправке изменений (`push`) в любую ветку репозитория запускается workflow, который восстанавливает зависимости .NET и выполняет автоматизированные тесты.

Результат выполнения тестов доступен во вкладке **Actions** репозитория.

## Назначение работы

Цель лабораторной работы — освоить методы проектирования и выполнения автоматизированных тестов на основе потокового графа, анализа базовых путей и выделения областей эквивалентности, а также научиться использовать GitHub Actions для автоматической проверки программного кода.
